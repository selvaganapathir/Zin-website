# Website analytics setup

The website currently has **no analytics tracker installed**. Visitor counts are not available from the site itself yet.

## Recommended option: Plausible

Plausible offers lightweight, privacy-oriented website analytics. Create an account and add the GitHub Pages hostname:

`selvaganapathir.github.io`

After the site is added and the provider gives you its exact installation snippet, place that snippet in `index.html` immediately before the closing `</head>` tag. Keep the provider's supplied domain value exactly as configured.

Example shape only (do not paste this placeholder as a working tracker):

```html
<script defer data-domain="YOUR-VERIFIED-SITE-HOSTNAME"
  src="https://plausible.io/js/script.js"></script>
```

Use the actual snippet from your account. Then open the public site, visit a few pages/sections and confirm the visit appears in the provider dashboard.

## Alternative: Google Analytics 4

If you prefer Google's ecosystem, create a GA4 property and web data stream for the exact GitHub Pages URL. Install only the Measurement ID and tag snippet generated by your own account. Review the provider's consent, retention and privacy settings before enabling it.

## Before enabling any provider

- Do not commit passwords, API secrets or private credentials.
- Use only the public website hostname; never configure tracking on the private blockchain repository.
- Publish a short privacy notice explaining the provider and data collected.
- Check applicable privacy and cookie requirements for the audiences and jurisdictions served.
- Re-test mobile performance after installation.

## Search Console (separate from analytics)

1. Open Google Search Console and add the website URL-prefix property: `https://selvaganapathir.github.io/Zin-website/`.
2. Complete the ownership verification method offered by Google.
3. Submit `https://selvaganapathir.github.io/Zin-website/sitemap.xml`.
4. Use URL inspection to request indexing after the site is accessible.
5. Monitor indexing and page experience reports. Submission does not guarantee indexing or ranking.

Analytics measures visits; Search Console reports search visibility. Neither guarantees traffic or search rankings.
